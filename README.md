# Hell's Factory Studio

โปรแกรมแปลและตรวจซับหลายตอนในที่เดียว ใช้ได้บน Windows, Mac และเว็บ
หน้าจอเลือกภาษาได้: ไทย / English / 中文

## ดาวน์โหลดตัวติดตั้ง

ไปที่แท็บ **Releases** ของ repo นี้
- Windows: ไฟล์ที่ลงท้ายด้วย `_x64-setup.exe`
- Mac: ไฟล์ที่ลงท้ายด้วย `_universal.dmg` (ใช้ได้ทั้ง Mac ชิป Intel และ Apple)

ตัวติดตั้งยังไม่ได้เซ็นรับรอง ครั้งแรกที่เปิด
- Windows จะขึ้นหน้าจอสีฟ้า "Windows protected your PC" ให้กด **More info → Run anyway**
- Mac ให้คลิกขวาที่แอป → **Open** แล้วกด Open อีกครั้ง

## ใช้งาน

- **โปรเจกต์** (กดชื่อโปรเจกต์มุมซ้ายบน หรือ Ctrl+Shift+P) แต่ละเรื่องแยกกัน ไม่ปนกัน เปิดโปรแกรมใหม่แล้วซับกลับมาเอง ไม่ต้องลากไฟล์ซ้ำ (วิดีโอต้องลากใหม่) ส่งออกเป็นไฟล์ `.hfproj` เพื่อย้ายเครื่องได้
- **คู่ภาษา** เลือกตอนสร้างโปรเจกต์: จีน→ไทย ไทย→จีน ไทย→อังกฤษ อังกฤษ→ไทย อังกฤษ→จีน จีน→อังกฤษ กฎตรวจปรับตามภาษาปลายทาง
- **เชื่อมต่อ AI** (☰ → เชื่อมต่อ AI) ใส่กุญแจของ Gemini / Claude / ChatGPT ครั้งเดียว ในเว็บ claude.ai ใช้ Claude ได้เลยไม่ต้องใส่กุญแจ
- **ลูกค้า · ไฟล์ guide** ลากคู่มือลูกค้า (PDF, Word, Excel, รูป) ให้ AI สรุปกฎ แล้วเลือกใช้ในช่อง "ลูกค้า" ลิมิตแนวตั้ง/แนวนอนเปลี่ยนเองตามวิดีโอ
- **ถาม AI** (Ctrl+J) แผงผู้ช่วยข้างจอ ถามความหมายคำ ขอคำแปลแบบอื่นแล้วกด "ใช้" ได้ทันที
- **ส่งออก** เลือกได้ ซับ / Excel / ทั้งสองแบบ
- **术语表** (Ctrl+G) แก้ เพิ่ม ลบ ค้นหา และส่งออก .xlsx ได้ในโปรแกรม

## การบันทึกงาน

- แก้แล้วบันทึกอัตโนมัติในเครื่องทันที กด **Ctrl+S** เพื่อบันทึกเดี๋ยวนั้นได้ ป้ายมุมบนบอกสถานะ (● ยังไม่บันทึก / ✓ บันทึกแล้ว)
- ปิดโปรแกรมแล้วเปิดใหม่ โปรเจกต์ล่าสุดเปิดขึ้นมาพร้อมงานที่แก้ค้างไว้
- ส่งงานให้ลูกค้ากด **Ctrl+E** ได้ zip ชื่อไฟล์เดิม ต่อ `_修改` เฉพาะตอนที่แก้ ไทม์โค้ดไม่เปลี่ยน
- **Ctrl+D** ทำเครื่องหมายว่าตอนนี้ตรวจเสร็จ แถบความคืบหน้าด้านบนนับให้
- คีย์ลัดทั้งหมดกด **F1**

## สำหรับนักพัฒนา

```
npm install
npm run dev          # เปิดเวอร์ชันเว็บที่ http://localhost:1420
npm run tauri dev    # เปิดแอปเดสก์ท็อป (ต้องมี Rust)
npm run build        # สร้างเวอร์ชันเว็บไว้ใน dist/
```

ตัวติดตั้ง Windows และ Mac สร้างอัตโนมัติด้วย GitHub Actions (`.github/workflows/release.yml`)
กด **Actions → Build installers → Run workflow** หรือ push tag ที่ขึ้นต้นด้วย `v` เช่น `v0.1.0`

โครงสร้าง
- `src/core.js` ตรรกะซับทั้งหมด (อ่าน/เขียน SRT ASS Excel, นับ SE/len, QA) ไม่แตะหน้าจอ
- `src/app.js` หน้าจอโปรแกรม
- `src/i18n/` ภาษาของหน้าจอ
- `src/platform.js` ส่วนที่ต่างกันระหว่างแอปเดสก์ท็อปกับเว็บ (บันทึกไฟล์)
- `src/ai.js` การเชื่อมต่อ AI (Gemini / Claude / ChatGPT / Claude ผ่าน claude.ai)
- `src/projdb.js` เก็บไฟล์ของแต่ละโปรเจกต์ไว้ในเครื่อง (IndexedDB)
- `e2e/` ทดสอบจริง: `run.mjs` แอป Windows ที่ติดตั้งแล้ว · `web.mjs` เวอร์ชันเว็บบน Chrome และ WebKit (Safari)
- `src-tauri/` ตัวแอปเดสก์ท็อป
